# CSPB 2270 – Data Structures - Term Project

If you have images of cells taken in two channels, you can use this code to determine how many cells in channel A are "near" cells in channel B, and how many cells in channel A are "far" from cells in channel B. This will only work if the cells are relatively round, and clearly separated from one another.
